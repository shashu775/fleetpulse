        We use .localhost rather than .local on purpose:
        RFC 6762 reserves .local for mDNS/Bonjour, so those lookups can bypass
        the hosts file and fail intermittently. .localhost is reserved for loopback
        by RFC 6761, and Chrome, Edge and Firefox resolve it internally.
